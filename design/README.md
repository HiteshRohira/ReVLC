# Design

`mockups.html` holds the static UI explorations (open with `?v=a|b|c&s=play|home`);
`shots/` has the rendered variants. Direction C was chosen.

Film stills in `assets/` are from Blender Foundation open movies (Big Buck Bunny,
Elephants Dream, Sintel, Tears of Steel, Spring, Cosmos Laundromat), licensed
CC-BY by the Blender Foundation (blender.org), via Wikimedia Commons.
